# Hangman Game

-Domain: Python Programming -Internship -Intern: Sunny Yadav -Organization: CodeAlpha

## Description

This is a simple text-based Hangman game made using Python.

The player has to guess a hidden word one letter at a time. The game randomly selects one word from a list of 5 predefined words.

The player can make a maximum of 6 incorrect guesses.

## Features

- Randomly selects a word
- Player guesses one letter at a time
- Shows correctly guessed letters
- Keeps track of incorrect guesses
- Maximum of 6 incorrect guesses
- Simple console-based game

## Concepts Used

- Random
- While loop
- If-else statements
- Strings
- Lists
- User input

## How to Run

1. Make sure Python is installed on your computer.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Run the following command:
python hangman.py
5. Or Click on Run Python File.
6. Enjoy!
