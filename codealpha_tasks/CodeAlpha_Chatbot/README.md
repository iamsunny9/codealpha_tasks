# Basic Chatbot

A simple rule-based chatbot built using Python. The chatbot responds to basic user inputs using predefined responses.

## Features

- Responds to greetings
- Responds to "how are you"
- Responds to "bye"
- Handles unknown inputs with a default response
- Runs continuously until the user types "bye"

## Technologies Used

- Python

## Concepts Used

- Functions
- if-elif-else statements
- while loop
- User input and output
- String handling

## How to Run

1. Make sure Python is installed on your computer.
2. Download or clone this repository.
3. Open the project folder in VS Code or any terminal. 
4. Then Run with Press ctrl+F5 or Run button.
5. Run the following command:
```bash
python chatbot.py
